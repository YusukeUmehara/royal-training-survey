# ROYAL 新人研修 振り返りアンケート

GitHub Pages で公開する、新人研修4日間の振り返りアンケートです。
回答は Google Apps Script 経由で、liberty.act2020@gmail.com のスプレッドシートに1行ずつ貯まります。

## ファイル構成
- `index.html` … アンケート本体（スマホ対応・5ステップ・途中保存つき）
- `config.js` … 回答の送信先URL（Apps Script のウェブアプリURL）
- `assets/` … ロゴ・ファビコン
- `gas/Code.gs` … スプレッドシート側に貼る受け取り用スクリプト（GitHubに置いても問題なし）

## 1. 回答用スプレッドシートの準備（初回のみ）
1. スプレッドシート「【回答】ROYAL新人研修 振り返りアンケート」を開く
2. メニューの「拡張機能」→「Apps Script」
3. 最初から入っているコードを全部消して、`gas/Code.gs` の中身を貼り付けて保存（⌘S）
4. 上部の関数の選択で `setup` を選んで「実行」→ 承認画面で自分のアカウントを選び、
   「詳細」→「（安全ではないページ）に移動」→「許可」
5. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車から「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」→ 表示された「ウェブアプリのURL」（https://script.google.com/macros/s/…/exec）をコピー

## 2. 送信先を設定
`config.js` の `endpoint` に、上のURLを貼る。
（未設定のあいだは画面上部に「テストモード」と出て、送信しても保存されません）

## 3. GitHub Pages で公開
1. GitHub で新しいリポジトリを作成（Public）
2. 「Add file」→「Upload files」で、このフォルダの中身をそのままアップロード
3. 「Settings」→「Pages」→ Branch を `main` / `/(root)` にして「Save」
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## メモ
- 同じ人が送信ボタンを連打しても、回答IDで二重登録を防ぎます
- Code.gs を直したときは「デプロイ」→「デプロイを管理」→ 鉛筆 →「新バージョン」で更新（URLは変わりません）
